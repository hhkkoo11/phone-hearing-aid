# 手机助听器：有线耳机稳定版

这是一个公益性质的 Android 本地助听辅助 App。当前公开主线是 **有线耳机稳定版**：优先让普通有线耳机、Type-C 标准音频耳机在居家、室内外短时间对话场景下稳定使用。

蓝牙耳机和骨传导耳机的代码会保留，但它们不是当前主线。因为蓝牙和骨传导受设备、系统延迟、耳机麦克风质量影响很大，实际效果不如有线耳机稳定。

## 当前稳定版

- 分支：`wired-stable`
- 版本：`wired-stable-1.6`
- 主线：有线耳机
- 实测反馈：有线耳机可用，讲话时沙沙/嘶嘶声已减少
- 回退点：`wired-stable-1.4`、`wired-stable-1.6`

## 主要功能

- 插入标准有线耳机或 USB 音频输出后自动进入可用状态。
- 手机麦克风收音，实时放大后播放到耳机。
- 后台和息屏场景下通过前台服务持续运行。
- 大号“小声 / 合适 / 大声”控制，适合老人直接使用。
- 保守的人声增强、远处人声温和抬升、轻度底噪处理。
- 输出限幅、反馈保护和长时间大音量提醒，降低不适风险。
- 蓝牙和骨传导作为备用能力保留，但不作为稳定版主推。

## 重要安全说明

本项目不是医疗器械，不能替代专业助听器、听力师验配、医院检查或医疗诊断。

请从较低音量开始，逐步调大。如果出现刺耳、耳痛、头晕、耳鸣、啸叫或明显不适，请立刻降低音量或停止使用。儿童、突发听力下降、单侧突然听不清、明显耳痛等情况应先就医。

不同手机、耳机、Type-C 转接器的音频硬件差异很大。某些助听器配套线材不会被 Android 识别为标准音频输出，本 App 无法通过软件强制破解硬件协议。

## 隐私

当前版本的麦克风音频在本机实时处理，不上传到服务器。App 内更新只会请求 GitHub 上的版本文件和 APK 文件。

## 构建

要求：

- JDK
- Android SDK 35
- Gradle 8.x

构建调试包：

```powershell
gradle assembleDebug
```

安装到已连接设备：

```powershell
adb install -r app\build\outputs\apk\debug\app-debug.apk
```

当前稳定版 APK 位于：

```text
release/hearing-aid-wired-stable.apk
```

## 更新配置

稳定版 App 会读取：

```text
https://raw.githubusercontent.com/hhkkoo11/phone-hearing-aid/wired-stable/release/wired-stable-version.json
```

普通 Android App 不能静默替换自己。即使检测到新版本，用户仍需要在系统安装页面手动确认安装。

## 当前开发原则

1. 先稳定有线耳机主线。
2. 不大改音频核心链路。
3. 每次只做小步优化，可编译、可安装、可回退。
4. 蓝牙和骨传导先保留，不作为当前主线。

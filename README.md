# 手机助听器

一个面向公益用途的 Android 本地助听辅助 App。它使用手机麦克风采集环境声音，经过人声增强、降噪、增益、限幅和反馈保护后播放到耳机里，重点优化蓝牙耳机日常使用，同时保留有线耳机室内对话模式。

> 当前状态：Alpha 测试版。已经可以在真实手机上运行和测试，但还没有经过医学验配、临床验证或多设备声压校准。

## 主要功能

- 蓝牙日常模式：适合日常生活场景，兼顾人声增强、降噪和远距离收声。
- 有线室内模式：面向室内对话，降低远距离收声带来的杂音。
- 重度模式：提供更高增益，同时保留限幅和啸叫保护。
- 口袋模式：降低衣物摩擦声和闷声影响。
- 大号 `+` / `-` 调节：方便老人直接调大或调小声音。
- 手机音量键联动：可用侧边音量键调节 App 增益。
- 输入电平显示：显示手机麦克风当前收到的声音大小。
- 持续大音量提醒：可开启或关闭。
- 后台耳机监测：检测到耳机后可自动进入可用状态。
- 简易听力测试：播放不同频率声音，辅助判断哪些频段更难听清。
- App 内检查更新：可通过云端 `version.json` 下发新 APK。

## 重要安全说明

本项目不是医疗器械，也不能替代专业助听器、听力师验配或医院检查。错误的增益、长时间大音量、啸叫和设备差异都可能带来听力风险。

建议使用方式：

- 从较低音量开始，慢慢调大。
- 如果刺耳、耳痛、头晕或出现啸叫，立刻降低音量或停止使用。
- 重度听力下降人群建议在家人陪同下测试。
- 儿童、突发性听力下降、耳鸣明显、耳痛或单侧突然听不清，应先就医。
- 蓝牙耳机存在不可完全消除的系统延迟，不适合所有场景。
- 某些 Type-C 助听器线材不会被 Android 识别为标准音频输出，本 App 无法强制破解这种硬件/协议限制。

## 隐私

音频处理在本机完成，当前版本不会把麦克风声音上传到服务器。App 内更新只请求云端版本文件和 APK 文件。

## 构建

要求：

- Android Gradle Plugin 项目环境
- JDK
- Android SDK 35
- Gradle 8.x

构建调试版：

```powershell
gradle assembleDebug
```

安装到已连接设备：

```powershell
adb install -r app\build\outputs\apk\debug\app-debug.apk
```

同步安装到所有已连接设备：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\install-all-devices.ps1
```

脚本会自动读取 `adb devices` 里所有在线设备并逐台安装。部分手机会弹出“允许安装”或“安装”确认，需要在手机屏幕上点确认。

## 云端更新配置

App 会读取代码中的 `UPDATE_JSON_URL`。云端 JSON 格式参考：

```json
{
  "versionCode": 2,
  "versionName": "1.1",
  "apkUrl": "https://example.com/hearing-aid/app-release.apk",
  "notes": "优化蓝牙耳机助听稳定性、人声清晰度和音量同步。"
}
```

发布新版本时：

1. 提高 `app/build.gradle` 里的 `versionCode` 和 `versionName`。
2. 构建 APK。
3. 上传 APK 到可信下载地址。
4. 更新云端 `version.json`。

普通 Android App 不能静默更新自身，用户仍需要在系统安装页面手动确认。

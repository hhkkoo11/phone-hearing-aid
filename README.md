# 手机助听器：有线耳机稳定版

一个公益性质的 Android 本地助听辅助 App。当前公开主线是 **有线耳机稳定版**，优先服务普通有线耳机、Type-C 标准音频耳机，用于居家、室内外短时间对话辅助。

> 本项目不是医疗器械，不能替代专业助听器、听力师验配、医院检查或医疗诊断。

## 当前稳定版

- 分支：`wired-stable`
- 版本：`wired-stable-1.7`
- 主线：有线耳机
- 实测反馈：有线耳机可用，讲话时沙沙/嘶嘶声已减少；更大声模式已增强，普通模式保持原稳定听感。
- 回退点：`wired-stable-1.6`、`wired-stable-1.7`

## 主要功能

- 插入标准有线耳机或 USB 音频输出后自动进入可用状态。
- 手机麦克风收音，实时放大后播放到耳机。
- 后台和息屏场景下通过前台服务持续运行。
- 大号“小声 / 合适 / 大声”控制，适合老人直接使用。
- 普通模式保持稳定听感，更大声模式用于重度耳背场景。
- 轻量去嘶声处理，减少讲话时的人声边缘沙沙声和嘶嘶声。
- 输出限幅、反馈保护和长时间大音量提醒，降低不适风险。
- 蓝牙和骨传导作为备用能力保留，但不作为稳定版主推。

## 最简单用法

1. 插上有线耳机。
2. 打开 App，允许麦克风权限。
3. 点“开始”。
4. 听不清就按“大声”，刺耳或沙沙声变多就按“小声”。
5. 重度耳背时，可在设置里打开“更大声模式”。如果刺耳、啸叫或沙沙声明显变多，请关闭。

## 自动化使用

App 已尽量做成老人少操作：

- 后台等待耳机连接。
- 检测到有线耳机或 USB 音频输出后自动准备助听。
- 开机后会尝试恢复耳机监测。
- 息屏和切到桌面后，通过前台服务继续工作。
- 如需听歌、刷视频或把耳机当普通耳机用，可在 App 里暂停自动助听。

不同品牌手机对后台运行限制不同。如果重启后不能自动监听，请在系统设置里允许本 App 后台运行、通知权限、麦克风权限，并关闭过度省电限制。

## 重要安全说明

请从较低音量开始，逐步调大。如果出现刺耳、耳痛、头晕、耳鸣、啸叫或明显不适，请立刻降低音量或停止使用。

儿童、突发听力下降、单侧突然听不清、明显耳痛等情况，应先就医。

不同手机、耳机、Type-C 转接器的音频硬件差异很大。某些助听器配套线材不会被 Android 识别为标准音频输出，本 App 无法通过软件强制破解硬件协议。

## 隐私

当前版本的麦克风音频在本机实时处理，不上传到服务器。App 内更新只会请求 GitHub 上的版本文件和 APK 文件。

## 构建

要求：

- JDK
- Android SDK 35
- Gradle 8.x

构建调试包：

```powershell
gradle assembleDebug
```

安装到已连接设备：

```powershell
adb install -r app\build\outputs\apk\debug\app-debug.apk
```

当前稳定版 APK 位于：

```text
release/hearing-aid-wired-stable.apk
```

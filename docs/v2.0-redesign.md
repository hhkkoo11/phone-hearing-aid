# 手机助听器 2.0 重构方向

## 核心目标

2.0 只围绕四件事做取舍：

1. 人声听得清楚。
2. 音量足够大。
3. 延迟尽量低。
4. 杂音、回声、电流声尽量少。

## 暂停继续堆功能

2.0 先不继续增加复杂功能，优先把收音链路做稳定。设置项只保留老人真正会用到的开关。

## 声音链路

默认从一个简单、直接、接近初代听感的链路开始：

麦克风输入 -> 轻度降噪 -> 人声频段保留 -> 动态压缩 -> 放大 -> 安全限幅 -> 耳机输出。

AI 降噪、远距离收声、自动增益、本人声音过滤都作为实验功能，默认不参与主链路，避免影响基础听感。

## 2.0 验收标准

每次改动只问这几个问题：

1. 人声是不是更清楚？
2. 音量是不是更够用？
3. 延迟有没有变大？
4. 有没有新增刺耳声、电流声、森林回声？
5. 息屏、切后台、重启后是否还能正常用？
